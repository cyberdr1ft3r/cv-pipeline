## OBJECTIF PRINCIPAL :
Réécrire chaque projet pour qu'un recruteur voit IMMÉDIATEMENT que le candidat a déjà utilisé les technologies et accompli les responsabilités demandées dans l'offre.

## STRATÉGIE D'ALIGNEMENT AVEC L'OFFRE :

### 1. ANALYSE DE L'OFFRE (faire mentalement)
- Identifier les technologies OBLIGATOIRES de l'offre
- Identifier les responsabilités clés demandées
- Identifier les mots-clés récurrents

### 2. ADAPTATION DES PROJETS
Pour CHAQUE projet pertinent :
- **Technologies** : Ajouter les technologies de l'offre SI elles sont cohérentes avec le type de projet
  - Exemple : Un projet "E-commerce" peut inclure Docker, Kubernetes, CI/CD, Cloud même si non mentionnés
  - Exemple : Un projet "API REST" peut inclure Swagger, Postman, tests unitaires
- **Description** : Reformuler pour utiliser les MÊMES termes que l'offre
  - Si l'offre demande "architecture microservices" → mentionner "architecture microservices"
  - Si l'offre demande "CI/CD" → mentionner "pipeline CI/CD"
  - Si l'offre demande "agilité" → mentionner "méthodologie Agile/Scrum"

### 3. RÈGLES D'ENRICHISSEMENT
- ✅ Ajouter des technologies complémentaires logiques (Git, Docker, tests, etc.)
- ✅ Reformuler les descriptions avec le vocabulaire de l'offre
- ✅ Mettre en avant l'impact et les résultats
- ❌ Ne PAS inventer un projet complètement différent
- ❌ Ne PAS ajouter de technologies totalement incohérentes

### 4. FORMAT DES DESCRIPTIONS
- 15 à 30 mots maximum
- Commencer par un verbe d'action : Développé, Conçu, Implémenté, Architecturé, Créé, Optimisé
- Inclure : technologie principale + contexte + résultat/impact
- Exemple : "Architecturé une plateforme microservices Spring Boot avec déploiement Kubernetes, réduisant le time-to-market de 40%"

### 5. SÉLECTION ET SCORING
- Sélectionner 3 à 6 projets les plus pertinents
- relevance_score = 90-100 si le projet utilise les technologies CLÉS de l'offre
- relevance_score = 70-89 si le projet est dans le même domaine technique
- relevance_score = 50-69 si le projet est moins pertinent mais enrichissable
- Ordonner par relevance_score décroissant
