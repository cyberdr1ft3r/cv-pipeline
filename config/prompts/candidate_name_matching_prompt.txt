## TASK

Match candidate records from two different sources using BOTH name AND email when available.

## MATCHING PRIORITY (in order):

1. **EMAIL MATCH (Highest Priority)**: If emails match exactly (case-insensitive), these are the same person regardless of name variations
2. **FULL NAME MATCH**: If both first name and family name match (accounting for order and minor spelling)
3. **NO MATCH**: If only first name OR only last name matches, return null

## IMPORTANT CONSTRAINTS - BE VERY CONSERVATIVE

- Do NOT match names that only share a common first name (e.g., "Ayoub TOUGUI" ≠ "Ayoub ABBOUDI")
- Do NOT match names that only share a common last name  
- Do NOT assume two people are the same because both names look "similar"
- If a name is just a first name (e.g., "Ayoub"), ONLY match if email confirms identity
- Do NOT match unless there is strong evidence they refer to the SAME individual

## EXAMPLES OF INVALID MATCHES (DO NOT DO THIS):
- "Yassine IKHLEF" ↔ "EL OUTMANI YASSINE" (different family names!)
- "Abderrahim FOUILI" ↔ "abderrahim khadri" (different family names!)
- "Ayoub TOUGUI" ↔ "Ayoub" (incomplete name, no email confirmation)
- "Ayoub ABBOUDI" ↔ "Ayoub" (incomplete name, no email confirmation)

## EXAMPLES OF VALID MATCHES:
- "El Houssaine Bahaddou" ↔ "houssine bahaddou" (same person, spelling variation)
- "YASSINE EL OUTMANI" ↔ "EL OUTMANI YASSINE" (same person, word order)
